
`3.14.8`, measuring all 294 statements and 100 branches with no misses or partial
branches. CI fails if `config_flow.py` falls below 100% coverage. Tests retain
selector restrictions: inputs rejected by Home Assistant's schema are checked as
such before defensive step validation is exercised.

The complete regression suite passed **167 tests**, with the same 100% flow coverage.
Ruff lint, formatting, dependency consistency and JSON/YAML/TOML checks passed.
The test run emitted five deprecation warnings from Home Assistant dependencies.
All 20 rules are accounted for: nine done, eight exempt and three awaiting upstream
publication. These results validate the development repository; no live integration
was installed or reloaded.

Setup failure tests distinguish permanent tariff errors from temporary
recorder/storage failures. Lifecycle tests show that unloading stops updates
and that a reload preserves registered entity identities. [Source identity
tests](../tests/test_source_identity.py) cover active and unloaded source renames,
legacy customized cost entities, preserved usage, alias reuse, availability and
late registry registration. Migration tests preserve existing contracts and settings.

HACS and Hassfest workflows remain separate checks. A local test run does not
establish that either remote validator passed.
