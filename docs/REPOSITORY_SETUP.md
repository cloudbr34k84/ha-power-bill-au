## First publication

From this directory, inspect `git status --short --untracked-files=all` and confirm the files
to publish. Keep raw bills, extracted invoice text, Home Assistant configuration and secrets
outside this directory. Commit the reviewed project files, then create the empty repository
with GitHub CLI or the GitHub website.

For GitHub CLI, after committing locally:

```sh
gh repo create cloudbr34k84/ha-power-bill-au --public --source=. --remote=origin \
  --description "Home Assistant electricity tariffs, import costs, solar credits and demand charges"
git push -u origin main
gh repo edit cloudbr34k84/ha-power-bill-au --enable-issues \
  --add-topic hacs,home-assistant,homeassistant,custom-integration,energy,electricity,tariff,aurora-smart-home
```

If the repository already exists, configure `origin` to its HTTPS or SSH URL and push the
reviewed commit instead. Use GitHub's credential manager or SSH authentication; keep tokens
out of remote URLs.
