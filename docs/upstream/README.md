describes `custom_integrations/` as legacy; the staged `core_integrations/` path is
for a future Core proposal. The [integration page structure](https://contributors.home-assistant.io/writing/reference/integration-page/)
provides the documentation layout and includes used in the draft.

The staged PNGs are unchanged copies: a 256×256 icon and a 512×512 icon.
Both are RGBA, fully opaque and non-interlaced. Transparency and interlacing are
preferred by the brands guidance, not required. Existing logo files are identical
to their corresponding icons, so the bundle includes icons only, as the guidance
requests; the upstream logo endpoint falls back to the icon.

The draft page omits `ha_release` and any quality-scale claim because neither a
Core release nor an official rating has been assigned. Review these drafts again
against upstream requirements when an actual Core proposal is ready.
